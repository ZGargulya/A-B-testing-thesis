# A-B-testing-thesis
## Дипломная работа по модулям обучения Python, А/В-тестирование
_____
**Цель работы** - оценить динамику пользовательской базы, активность игроков, финансовые результаты, собрать результаты технических заданий в единую структуру

**Легенда:** я работаю аналитиком данных в крупном ретейлере SkyLenta в отделе продуктовой аналитики, задача от руководства — проанализировать результаты A/B-теста, чтобы принять обоснованное решение о смене маркетинговой механики.
Ожидаемый результат - оформить результаты исследования в форме удобного Excel-калькулятора.

*Что делала:*

*Выполнила загрузку данных в Jupyter Notebook, очистила и подготовила их к дальнейшему анализу. Объединила три таблицы в одну. Очистила датафрейм от неверно заполненных торговых точек.

*Для автоматизации статистических вычислений создала функции для расчета критериев Стьюдента и Манна-Уитни.

*С помощью гистограммы визуализировала распределение средних платежей, провела тестирование, применив функции, сделала выводы.

*Провела сегментацию по городам и торговым точкам и рассчитала результаты A/B-теста на каждом сегменте.

*Отчет по А/В-тесту преобразовала в новую таблицу, результаты исследования выгрузила в Excel.

*Оформила результаты в таблицу-калькулятор, которая для каждой торговой точки показывает влияние изменения механики уведомлений на прирост или падение выручки.

**Формат курсовой** - Работа выполнена в Jupyter Notebook, создание калькулятора в Excel.

Используемые инструменты ***Python*** (EDA, функции, циклы, визуализация ), Excel.
